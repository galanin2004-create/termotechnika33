# ТЕРМОТЕХНИКА33 — сайт

Одностраничный сайт компании «ТЕРМОТЕХНИКА33 · Котлы & Насосы» — монтаж отопления, тёплого пола
и водоснабжения в частных домах. Владимир и Владимирская область, с 2014 года.

Статика без сборки: HTML, CSS и один файл на ванильном JS. Внешние зависимости — только шрифты
Oswald и Golos Text с Google Fonts.

## Запуск

```bash
node server.js
```

Откроется на http://localhost:4173. Можно и просто открыть `index.html` в браузере —
локальный сервер нужен только для корректной отдачи путей и MIME-типов.

## Структура

```
index.html      разметка всех секций
styles.css      стили, переменные бренда в :root
script.js       меню, маска телефона, валидация формы, просмотр фото, свечение
img/            фотографии объектов, отобранные по фотостилю
server.js       статический сервер для локального просмотра
```

## Правила бренда

Сайт собран по бренд-буку 2026. При правках их нужно соблюдать.

**Цвета.** Графит `#17191C` (основа, тексты), пламя `#EE6A1E` (акцент, кнопки, «33»),
латунь `#F2B33D` (второй акцент), сталь `#2C3440` (блоки на тёмном), бумага `#F3F0EA` (фон).
Пропорция: 60% графит и бумага, 25% нейтральные, 15% акцент — оранжевого не больше 15%.

**Шрифты.** Oswald — заголовки, только Medium и SemiBold, прописными, трекинг 0…+2%.
Golos Text — текст, Regular и SemiBold, интерлиньяж 150%, строка не длиннее 70 знаков.

**Кнопки.** Основная — оранжевая заливка и графитовый текст, вторая — контурная.
Без скруглений и теней. Текст кнопки — действие клиента, не «отправить».

**Форма.** Максимум три поля: площадь дома, что нужно, телефон.
Под кнопкой — «Перезвоним в течение часа, в выходные тоже».

**Тексты.** В каждом блоке минимум одна конкретика: площадь, срок, цена или гарантия.
Без восклицаний, скидок-таймеров, канцелярита и «инновационных решений».

**Что говорим о работе.** Дома от 30 до 1000 м², запуск котельной от 1 дня,
гарантия на монтаж 1 год. Формулировки «под ключ» не используем. Договор не подаём
как обязательное условие: работа по договору с проектом — отдельная возможность
по запросу, о ней сказано в разделе «Как работаем».

**Фото.** Только свои объекты, дневной свет, ровный горизонт, видно качество пайки и крепежа.
Не идут: сток, коллажи, мусор и грязь в кадре, тяжёлые фильтры.

## Что не доделано

- Форма заявки не отправляет данные: показывает подтверждение. Отправку в CRM
  или на почту нужно подключить в `script.js` (место отмечено комментарием).
- Мессенджеров в контактах нет: на termotechnika33.ru иконки Telegram и WhatsApp стоят
  без ссылок. Нужны подтверждённый номер WhatsApp и ник в Telegram.
