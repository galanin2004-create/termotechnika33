# ТЕРМОТЕХНИКА33 — сайт

Одностраничный сайт компании «ТЕРМОТЕХНИКА33 · Котлы & Насосы» — монтаж отопления, тёплого пола
и водоснабжения в частных домах. Владимир и Владимирская область, с 2014 года.

Статика без сборки: HTML, CSS и один файл на ванильном JS. Внешние зависимости — только шрифты
Oswald и Golos Text с Google Fonts.

## Запуск

```bash
node server.js
```

Откроется на http://localhost:4173. Можно и просто открыть `index.html` в браузере —
локальный сервер нужен только для корректной отдачи путей и MIME-типов.

## Структура

```
index.html      разметка всех секций
privacy.html    политика конфиденциальности (черновик, реквизиты — в квадратных скобках)
styles.css      стили, переменные бренда в :root
script.js       меню, маска телефона, отправка формы, просмотр фото, свечение
img/            фотографии объектов и логотип; brands/ — логотипы поставщиков
server.js       статический сервер для локального просмотра
```

## Приём заявок

Форма шлёт заявку через FormSubmit на **domostroyv@mail.ru** (AJAX, без перезагрузки).
Адрес и текст письма задаются в `script.js` — константа `FORM_ENDPOINT` и тело `fetch`.

**Первую заявку нужно активировать один раз:** после первой отправки FormSubmit пришлёт
на domostroyv@mail.ru письмо со ссылкой-подтверждением — по ней надо кликнуть, иначе
следующие заявки не дойдут. Дальше всё работает автоматически.

Защита от спама — скрытое поле-ловушка (honeypot): если бот его заполнил, заявка тихо
отбрасывается. Согласие на обработку данных — обязательная галочка со ссылкой на `privacy.html`.

Заменить приёмник на Telegram-бот или CRM можно, поменяв `FORM_ENDPOINT` и обработчик
`fetch` в `script.js`.

## Правила бренда

Типографика и вёрстка — по бренд-буку 2026, цвета — по логотипу «Котлы & Насосы».

**Цвета.** Взяты из логотипа: красный `#E32226` (кнопки, акценты, «33») и голубой
`#00A3E0` (подписи, счётчики, свечение). Тёмная база `#14202B`, блоки на тёмном `#1E2E3D`,
светлый фон `#F5F8FA`. Шапка белая — логотип на ней лежит без плашки.

**Шрифты.** Oswald — заголовки, только Medium и SemiBold, прописными, трекинг 0…+2%.
Golos Text — текст, Regular и SemiBold, интерлиньяж 150%, строка не длиннее 70 знаков.

**Кнопки.** Основная — красная заливка и белый текст, вторая — контурная.
Без скруглений и теней. Текст кнопки — действие клиента, не «отправить».

**Форма.** Максимум три поля: площадь дома, что нужно, телефон.
Под кнопкой — «Перезвоним в течение часа, в выходные тоже».

**Тексты.** В каждом блоке минимум одна конкретика: площадь, срок, цена или гарантия.
Без восклицаний, скидок-таймеров и канцелярита.

**Что говорим о работе.** Дома от 30 до 1000 м², обвязка котельной для пуска газа
от 1 дня, гарантия на монтаж 1 год. Формулировки «под ключ» не используем. Договор
не подаём как обязательное условие: работа по договору с проектом — отдельная
возможность по запросу, о ней сказано в разделе «Как работаем».

**Фото.** Только свои объекты, дневной свет, ровный горизонт, видно качество пайки и крепежа.
Не идут: сток, коллажи, мусор и грязь в кадре, тяжёлые фильтры.
